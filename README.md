## How to get the click animations

- Download the latest [Galaxy Cursor release](https://github.com/sebastianheder01/Galaxy-Cursor/releases/latest) and extract it to a permanent local folder
- Download and install [AutoHotkey v2](https://www.autohotkey.com/)
- Open `click-animations` and keep `click-animations.ahk`, `impulse.bgra`, `orbit.bgra`, and `particle.bgra` together
- Double-click `click-animations.ahk` to start the animations; each left-click plays the selected effect
- Right-click the AutoHotkey tray icon to choose Impulse, Orbit, or Particles, toggle the animations, or exit the script
- To start it automatically when you sign in, press `Win + R`, enter `shell:startup`, and place a shortcut to `click-animations.ahk` in that folder.

You can also hold `4`, `5`, or `6` on the numeric keypad and press `+` to select Impulse, Orbit, or Particles, or define your own hotkeys in `click-animations.ahk`. 
The click animations work independently of Windhawk and your selected cursor scheme.

## How to get the common additional cursors

- Download the latest [Galaxy Cursor release](https://github.com/sebastianheder01/Galaxy-Cursor/releases/latest) and extract it to a permanent local folder
- Download and install [Windhawk](https://windhawk.net/)
- Install the [Cursor Override](https://windhawk.net/mods/cursor-override) mod in Windhawk
- Open the mod's Settings tab and enter the full local path to the matching .cur or .ani file for each cursor you want to replace
